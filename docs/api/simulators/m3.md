# M3 simulator

Use `simulate_m3_custom()` for M3-style response-count workflows. The simulator
receives model parameters from a workflow, passes them to your activation
function, converts activations to choice probabilities, and samples response
counts.

Use `prop_m3()` only when a workflow should keep raw counts but train on
response proportions.

### `prop_m3(row, n_trials)`

Convert one M3 count row to response proportions. Use it as
`row_transform=prop_m3` when a workflow should retain raw counts separately but
train on proportions.

## Direct use

```python
from bami.simulators import simulate_m3_custom


def m3_activation(a, c, ra, rc, b=0):
    return [a + c + b, a + b, ra * a + rc * c + b, ra * a + b, b]


counts = simulate_m3_custom(
    a=0.8,
    c=0.9,
    ra=0.3,
    rc=0.4,
    b=0,
    n_trials=80,
    activation_fn=m3_activation,
    n_options=[1, 3, 1, 3, 4],
)
```

## Simple workflow

```python
from bami.simulators import simulate_m3_custom
from bami.workflows import SimpleWorkflow


def m3_activation(a, c, ra, rc, b=0):
    return [a + c + b, a + b, ra * a + rc * c + b, ra * a + b, b]


model = SimpleWorkflow(
    name="M3",
    param_names=["a", "c", "ra", "rc"],
    priors={
        "a": {"mean": "normal(0.8, 0.5)", "sd": 0.2, "link": "log"},
        "c": {"mean": "normal(0.8, 0.5)", "sd": 0.2, "link": "log"},
        "ra": {"mean": "logistic(0, 0.75)", "sd": 0.5, "link": "logit"},
        "rc": {"mean": "logistic(0, 0.75)", "sd": 0.5, "link": "logit"},
        "b": 0,
    },
    simulator=simulate_m3_custom,
    observation="aggregate",
    simulator_kwargs={
        "activation_fn": m3_activation,
        "n_options": [1, 3, 1, 3, 4],
        "rule": "softmax",
    },
    obs_names=["correct", "other", "dist", "other_dist", "new"],
    n_trials=80,
)
```

## Proportion inputs

Use `row_transform=prop_m3` when a workflow should train on response
proportions while retaining raw counts separately for posthoc checks.
